Selected Research and Publications

* Equal contribution. Full publication list.

OmniSSR: Zero-shot Omnidirectional Image Super-Resolution using Stable Diffusion Model

Runyi Li*, Xuhan Sheng*, Weiqi Li, Jian Zhang. ECCV 2024, Oral.

  • Contributed to method design, implementation, and evaluation of zero-shot panoramic super-resolution using diffusion priors, tangent-view information exchange, and gradient decomposition.

PanoForcing: Enforcing Memory-Scalable Full-Context for Blind Panoramic Super-Resolution

Xuhan Sheng (first author), et al. Under review, ICLR 2027.

  • Led design, implementation, and core experiments for one-step panoramic diffusion super-resolution. Preserved full panoramic context while controlling training memory via selective autograd recording and inference memory via face-level parallelism.
  • Designed Fourier pseudoinverse guidance to constrain reconstructed details using low-resolution observations within a single network pass.

RealOSR: Latent Guidance Boosts Diffusion-based Real-world Omnidirectional Image Super-Resolutions

Xuhan Sheng*, Runyi Li*, Bin Chen, Weiqi Li, Xu Jiang, Jian Zhang. Preprint, arXiv:2412.09646.

  • Major contributor to implementation and experiments; used latent-space guidance to constrain one-step diffusion reconstruction for real-world panoramic super-resolution.

OmniDrag: Enabling Motion Control for Omnidirectional Image-to-Video Generation

Weiqi Li, Shijie Zhao, Chong Mou, Xuhan Sheng, et al. IJCV 2026.

  • Contributed to the Move360 large-motion dataset for controllable panoramic image-to-video generation.

Label-guided Facial Retouching Reversion
